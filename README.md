## 我们在做什么

节点手册面向中文用户整理可复核的网络工具资料。内容重点包括：

- Clash Verge、v2rayN、v2rayNG、Shadowrocket、Surge、sing-box 等客户端的安装、导入与排错；
- 机场公开套餐、付款方式、线路描述、入口状态与风险提示；
- 免费节点候选的跨来源去重、连通筛选、第三方测速与历史归档；
- 出口 IP、ASN、地理位置、住宅/机房标签和 DNS 泄漏的核验方法；
- 订阅失败、TUN 断网、晚高峰变慢、连接成功但打不开网页等常见问题。

## 内容原则

1. **事实与宣传分开**：公开线路标签不等于本站实测，也不自动证明速度、稳定性或解锁能力。
2. **保留时间和来源**：价格、流量、入口、测试与风险记录注明核对时间和证据边界。
3. **失败结果同样保留**：未连通、丢包过高、地区冲突或测试未完成的节点不会包装成可用节点。
4. **保护敏感信息**：不公开私人订阅、令牌、账号、密码、支付信息或未脱敏日志。
5. **拒绝批量薄内容**：同一搜索意图使用一个主页面，更新必须增加真实数据、诊断步骤或原创分析。

## 免费节点测试口径

公开候选先按协议、服务器和端口去重，再进行服务器连通预筛。预筛通过只代表候选优先级，不代表节点合格。

当前正式发布采用双探针真实代理请求：站点 VPS 与另一台独立公网出口主机各完成 10 次 HTTPS 请求及一次固定小文件下载。两端均至少成功 9 次、固定下载均成功，并且至少两家 IP 地理来源一致，才可进入合格下载。10 次请求的失败比例称为**请求失败率**，不能写成网络丢包率。

海豚测速可作第三方佐证；只有确实完成测速并保存原始证据时，才报告其后端、排序、类型和丢包率。未完成时明确说明，不以自有测试冒充海豚结果。

历史节点可能随时失效。日期文章保存的是当日结果，不代表今天仍然可用。

更完整的筛选、去重、证据与发布边界见 [免费节点测试方法](FREE-NODE-METHODOLOGY.md)。

## 机场资料核验

机场页面重点记录以下可核对字段：

| 字段 | 核验方式 |
| --- | --- |
| 公开入口 | HTTP 状态、最终跳转和核对时间 |
| 套餐价格 | 官方公开页或结算页，不把年付折算冒充月付 |
| 流量与倍率 | 标称流量、节点倍率、重置周期和有效期分别记录 |
| 线路描述 | 保留“服务方标注”层级，不推断完整物理拓扑 |
| 支付方式 | 区分支付宝、微信、USDT、PayPal及其退款和到账限制 |
| 解锁能力 | 只有带节点、地区、时间、登录状态和截图的测试才写成本站结果 |
| 风险 | 区分 403、临时故障、入口迁移与有证据的停运信息 |
