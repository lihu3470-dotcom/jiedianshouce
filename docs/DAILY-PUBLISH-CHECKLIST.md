# 每日发布一致性清单

本清单用于防止当天内容只更新一部分入口。任何一项不一致，都不能报告“已完成”。

## 当前批次唯一性

- 免费节点固定页只能出现一个“今日批次”，不得同时保留昨天的“今日”按钮、主体或弹窗。
- 网站首页、免费节点固定页、日期历史帖和更新记录中的日期、候选数、完成测试数、严格合格数与观察数必须一致。
- 观察节点与严格合格节点必须分开统计；总下载说明必须与实际文件内容一致。

## 公开入口同步

- 网站首页当天入口与文案。
- `/free-nodes/` 顶部结论、正文、按钮和下载弹窗。
- 当天永久日期页、历史归档、每日更新记录和更新归档。
- 文章库、站内搜索、RSS和站点地图。
- GitHub README、CHANGELOG、主题地图和公开站点地图。

## 文件与证据

- 总下载、每个单条下载和页面显示数量一致，并逐项返回HTTP 200。
- 测速原图、完成时间、测试后端、运营商、测试类型与SHA-256可核对。
- 不把候选、预筛通过、未完成或观察结果写成严格合格。
- 不上传节点配置、服务器地址、私人订阅、令牌、账号或未脱敏日志到GitHub。

## 上线验收

- 对生产页面使用无缓存请求，不以本地预览代替线上检查。
- 搜索旧日期、旧数量和旧“今天”文案；若在当前入口仍出现，发布判定失败。
- 检查单一H1、self-canonical、结构化数据、移动端布局和关键状态码。
- 保持 `/free-nodes/` 与 `/airports/` 的URL、标题主体、H1、canonical和主要搜索意图稳定。
- 生产验收通过后再同步GitHub，并在CHANGELOG记录实质变更和修复。
